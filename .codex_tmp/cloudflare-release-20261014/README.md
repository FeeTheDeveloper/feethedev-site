# Fee The Developer

Public website and portfolio catalog for Fee The Developer. The application uses the signal-system visual language documented in [DESIGN.md](DESIGN.md) and presents selected work with explicit live, review-build, and technical-case-study labels.

## Local verification

```bash
npm ci
npm run format:check
npm run lint
npx tsc --noEmit
npm run build
```

Portfolio claims are grounded in repository and public-surface evidence. External provider state, client approval, legal status, pricing, and deployment state require current authoritative verification.
