## October 5, 2026 — color photos and live Payment Links

The user supplied 16 product photos covering heather gray, royal blue, vivid red, and sage green for all four items. They are stored unchanged in `public/merch/` as `<product>-<color-slug>.jpg`. White keeps its existing assets: `white-hoodie-front.png` for the hoodie and crops of `full-line-reference.png` for the joggers, T-shirt, and hat.

`lib/merch.ts` now models each product as a list of color variants (`color`, `colorSlug`, `swatch`, `image`, optional `imageCrop`). `components/MerchCard.tsx` replaces `MerchOptions.tsx`: the color dropdown swaps the card photo, shows a swatch dot, and selects that color's checkout link. The size dropdown stays on apparel.

Twenty live Payment Links were created in the Fee The Developer LLC account (`acct_1TCTjGHWhC70mvOk`) by `scripts/create-merch-payment-links.mjs`, one per product and color. Each link carries one unit of the product's existing price, a Color dropdown preselected to that color, a Size dropdown on apparel, phone number collection, shipping address collection limited to the United States, and the verified `shr_1UMWVbHWhC70mvOk4sfQd08F` $12.99 rate. All twenty were read back and matched that configuration. The user approved US-only shipping on October 5.

Each `MERCH_*_STRIPE_LINK` variable now holds a JSON object mapping color slug to Payment Link, which `resolveCheckoutLinks` parses; a single `buy.stripe.com` URL still works and is reused for every color, and any other value falls back to the inquiry button. The four values are set in `.env.local` and still need to be set in Vercel for Production, Preview, and Development. The buy button appends `client_reference_id=<product>-<color>-<size>` so the site's selection is recorded on the Checkout Session alongside the shopper's own dropdown picks.

Re-running the script is safe: it reuses any active link whose metadata already names the same product and color. `npm run merch:links` is a dry run; `npm run merch:links -- --apply` writes. Shipping destinations can be widened with `--countries=US,CA`, which requires creating new links or editing the existing ones in Stripe.

Still open: fulfillment capacity, whether the flat $12.99 covers every order, and a print-quality proof of the garment art against production garments.
